## File
- `index.html` — struktur halaman
- `style.css` — desain hitam + navy, responsif/fluid
- `script.js` — jam lokal, status tanggal, animasi reveal, galeri lightbox, progress bar
- `data.json` — data nama, tanggal, lokasi, foto
- `assets/images/` — 5 foto asli yang diberikan
- `assets/favicon.svg` — favicon

## Catatan waktu
Jam memakai timezone perangkat/browser pengunjung melalui JavaScript `Intl.DateTimeFormat()`, jadi waktu tampil mengikuti lokasi/timezone perangkat yang mengakses halaman.

## Foto
Foto pasangan di `assets/images/` adalah foto yang diberikan untuk website ini.
Foto dekorasi tambahan menggunakan hotlink dari Unsplash (`images.unsplash.com`). Lisensi Unsplash mengizinkan penggunaan foto secara luas, namun jika website dipublikasikan secara komersial, tetap cek ketentuan lisensi terbaru dari penyedia.

## GitHub Pages
Upload seluruh isi folder ini ke repository GitHub, lalu aktifkan:
Settings → Pages → Deploy from branch → pilih branch `main` dan folder `/root`.
